# 에셋 찾기 → 영상 안 테스트 → 고른 것만 쓰기

사용자는 **비교 화면을 보고 번호만 고른다.** 검색·다운로드·테스트는 전부 에이전트가 한다. 원본 사진을 먼저 보여 주지 않는다.

## 1. 연관어 확장
키워드를 뜻으로 이해해 6~10개로 넓히고 가중치(0.3~1.0)를 매긴다. 파일명 일치가 아니라 의미로.
- `sky` → `sky:1` `cloud:0.8` `sunset:0.7` `starry sky:0.7` `aurora:0.5` `gradient sky:0.5`
- 지금 만드는 영상의 분위기(색, 캐릭터)를 반영한다.
- 사람·글자·워터마크가 잘 들어가는 말(poster, people)은 피한다.

## 2. 검색·다운로드
```bash
python3 find_assets.py public/candidates/<이름> "<연관어>:<가중치>" ... --top 12 --models 2      # 2D + Poly Haven
python3 find_assets.py public/candidates/<범주> "<연관어>:<가중치>" ... --top 0 --models 0 --3d 12  # 3D
python3 fetch_models.py public/candidates/<범주>                                                   # 3D 원본
```
- 3D 범주가 여러 개면 **범주별로 따로** 돌린다(한 번에 돌리면 한쪽으로 쏠린다).
- 키: `POLYPIZZA_KEY`, `SKETCHFAB_TOKEN`(환경변수 또는 `.secrets/` 파일). Sketchfab 401 이면 토큰을 다시 받으라고 말한다.
- 로그인이 필요한 사이트는 받지 않는다. `candidates.json` 의 `links` 에 검색 링크만 있다.

## 3. 영상 안 테스트
- 2D: 지금 작업 중인 컷의 배경 프롭에 후보를 하나씩 넣어 스틸을 찍고(번들을 한 번 만들고 차례로, 병렬 금지) `BgSheet` 로 비교표.
- 3D: `PropGrid` 컴포지션에 `items` 를 넣고 Studio 에서 회전 화면으로 보여 준다. 15MB 넘는 파일은 아예 목록에서 뺀다.
- **보여 주기 전에 에이전트가 먼저 본다.** 엉뚱한 것(제목만 맞은 것), 워터마크, 누운 채 안 세워진 것, 텍스처 빠진 것은 빼고 보여 준다.

## 4. 고른 것만 쓰기
- 원본을 프로젝트 소재 폴더로 옮기고, `license` 가 CC0 가 아니면 작가·라이선스·링크를 크레딧 파일에 한 줄 남긴다.
- 후보 폴더는 깃 제외로 두고 끝나면 지운다.
